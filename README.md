# Cours : les agents IA, de zéro à expert

Cours vidéo en français, en 18 modules et 4 niveaux, pour les développeurs. Chaque vidéo est narrée (voix de synthèse) et sous-titrée, avec des exemples en TypeScript, Java (Spring Boot) et Angular, et se termine par un atelier pratique.

**Prérequis** : savoir coder et appeler une API REST. Aucune connaissance en IA nécessaire.

**Projet fil rouge** : un assistant pour une équipe de développement, enrichi module après module, jusqu'au déploiement en Spring Boot + Angular.

Durée totale des vidéos : environ 1 h 46 min (hors ateliers pratiques).

## Utilisation

- Les vidéos sont dans `videos/`. Sur GitHub, ouvre un fichier puis « View raw » ou « Download » pour la lire.
- Les sous-titres `.srt` (dans `sous-titres/`) se chargent dans VLC ou s'importent sur YouTube.
- Les exemples de code et les noms de bibliothèques reflètent l'état de l'écosystème fin 2026 : vérifie la documentation à jour avant de les réutiliser.
